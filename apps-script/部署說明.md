# 報到系統部署說明（v2：年齡分流＋網頁問卷＋個人工作人員帳號）

> ⚠️ **順序很重要：先完成 Apps Script（第 1～5 步），再推送活動網頁（第 6 步）。**
> 新版網頁會呼叫新版 Apps Script（要帶年齡、送問卷），反過來做會報到失敗。

## 活動流程總覽

| 參加者 | 報到 | 活動內容 | 領取 |
|---|---|---|---|
| 有手機（12歲以上） | 自己用手機報到 → 畫面「✓ 已報到」給入口看 | 認識情緒行為障礙 5 題（全對）→ 心情溫度計（必要時心理師密碼 1031）→ 網頁問卷（匿名） | 說序號＋姓名 |
| 有手機（未滿12歲） | 同上，年齡選「未滿12歲」 | 兒童版 5 題（看解答、可答錯）→ 完成 | 同上 |
| 沒有手機 | 櫃台工作人員「代為報到」，告訴對方序號 | 在共用平板或家長手機選「我已經有序號」輸入，依年齡自動分流 | 同上 |

- 「完成狀態」由網頁自動寫回試算表；領取時系統會檢查「已完成」才能按確認，且每個序號只能領一次。
- 問卷存在「問卷回覆」分頁，**不含姓名、手機、序號**（匿名）。原本的 Google 滿意度表單不再使用。

## 1. 貼上新程式碼

1. 打開報到試算表 →「擴充功能」→「Apps Script」。
2. 把 `Code.gs` 原本的內容**全部刪除**，貼上本資料夾 `Code.gs` 的內容，按儲存（Ctrl+S）。

## 2. 設定指令碼屬性

左側齒輪「專案設定」→ 最下方「指令碼屬性」：

| 屬性 | 值 |
|---|---|
| `MITAKE_USERNAME` | 三竹帳號 |
| `MITAKE_PASSWORD` | 三竹密碼 |
| `STAFF_ACCOUNTS` | 打開本機 `private/staff-accounts.txt`，整行複製「值」那一行貼上 |
| `MAX_CODES` | （選填）序號上限，例如 `220`；不填預設 500（SEM001～SEM500） |

- 舊的 `STAFF_PIN` 屬性已不再使用，可以刪除。
- `private/` 資料夾只在你的電腦上，不會上傳到 GitHub。密碼卡可開 `private/staff-accounts-print.html` 列印裁切。
- 想把「工作人員01」改成真實姓名：在屬性值裡直接改名稱（格式 `名稱:密碼`，用逗號分隔），試算表的「代報經辦人／領取經辦人」就會顯示該名稱。

## 3. 執行初始設定與測試

1. 函式選單選 `setup` → 執行（第一次會要求授權，請允許）。
   - 會建立「報到名單」（新欄位：年齡組別、報到方式、代報經辦人、完成狀態…）與「問卷回覆」兩個分頁。
   - 執行紀錄會顯示屬性是否都已設定、工作人員帳號數（應為 10）。
2. 函式選單選 `testConnection` → 執行，確認有剩餘點數（不發簡訊、不花點數）。

> 舊的「報到名單」欄位順序不同。如果裡面只有測試資料，建議**整個分頁刪除**再執行 `setup`，讓它重建。

## 4. 刪除舊的觸發條件

左側「觸發條件」（鬧鐘圖示）→ 把 `onFormSubmit` 那一筆**刪除**（新版不再使用備用表單，留著會執行失敗）。

## 5. 更新部署

右上「部署」→「管理部署作業」→ 點現有部署旁的鉛筆 →「版本」選「**新版本**」→ 部署。

- ⚠️ 一定要用「編輯現有部署」，**不要按「新增部署作業」**，否則網址會改變，活動網頁會連不到。
- 「執行身分」維持「我」，「誰可以存取」維持「所有人」。

## 6. 推送活動網頁

在 GitHub Desktop 按 **Push origin**，約 1～2 分鐘後網站更新。

## 7. 活動前測試（建議實際走一次）

1. 手機從 LINE 開活動網頁 → 報到（年齡選 12歲以上）→ 收到簡訊、畫面顯示「✓ 已報到」與序號。
2. 完成 5 題 → 心情溫度計 → 問卷 → 出現「✓ 已完成」。試算表「完成狀態」變成「已完成」，「問卷回覆」多一列。
3. 工作人員頁（Apps Script 部署網址）用個人密碼登入 → 「代為報到」一位未滿 12 歲、不填手機 → 得到序號。
4. 平板開 `活動網址?kiosk=1`（只需開一次，這台會記住）→ 輸入剛剛的序號 → 應直接進入兒童版 → 看解答 → 完成 →「完成，換下一位」回到首頁。
5. 工作人員頁「領取查詢」輸入序號（只打數字即可，1 或 001 都是 SEM001；忘記序號時切換「用姓名查」）→ 核對姓名 → 確認領取。再查一次應顯示「已領取 時間 經辦人」，無法再領。
6. 測試完成後清空：把「報到名單」與「問卷回覆」第 2 列以下整列刪除（保留標題列），序號會從 SEM001 重新開始。

## 現場裝置

- **共用平板**：網址加 `?kiosk=1`。報到頁預設「我已經有序號」；完成後有「完成，換下一位」；閒置 2 分鐘自動清除回首頁。要取消平板模式，開一次 `?kiosk=0`。
- **工作人員手機（3 支）**：開 Apps Script 部署網址，各自用自己的密碼登入。
- 網頁報到持續失敗時，畫面會請參加者到櫃台，由工作人員代為報到；最後備案是紙本簽到單。

## 安全說明

- 名稱結尾有底線的函式（如 `sendSms_`、`createRow_`）外部無法呼叫，**請勿移除底線**。
- 工作人員頁的每個動作都要帶個人密碼，密碼錯誤會延遲回應；手機號碼只顯示前 4 碼與末 3 碼。
- 活動結束後建議：更改三竹密碼、刪除 `STAFF_ACCOUNTS`、依規定處理「報到名單」個資。
